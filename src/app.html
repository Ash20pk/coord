Install

Enrol the repository, then commit what it writes

Store this team’s token on the machine

Run the daemon and confirm it is on

knoot daemon
knoot status

See it work

knoot fails open, so a quiet log proves nothing on its own. Start two sessions in an enrolled repository and give both the same file.

KNOOT_USER=ash claude
KNOOT_USER=priya claude

The second session is handed a conflict brief naming the first, and the refusal appears in the log as claim_denied.
