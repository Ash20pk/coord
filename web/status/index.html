Checking the relay

These checks run in your browser, against the relay that served this page. They are the same surfaces your agents use, so a failure here is a failure they would see.

What an outage means for your agents

knoot fails open. If the relay is unreachable, agents are not blocked: every hook resolves to allow and sessions carry on uncoordinated, exactly as they would without knoot installed. You lose collision prevention for the duration, not the ability to work.

Because of that, silence from an agent proves nothing. Run knoot status on a machine to see whether coordination is actually on.
